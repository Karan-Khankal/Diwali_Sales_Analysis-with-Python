# 🪔 Diwali Sales Analysis using Python

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on Diwali sales data to uncover customer purchasing behavior and key sales trends.

## 🎯 Objectives
- Identify high-spending customer segments
- Analyze gender and age-wise purchasing power
- Find top-performing states
- Determine most sold product categories
- Study marital status vs spending patterns

## 🛠️ Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🔄 Project Workflow
1. Data Cleaning
2. Handling Missing Values
3. Exploratory Data Analysis
4. Data Visualization
5. Business Insights

## 📊 Key Insights
- Married women aged 26–35 were the highest spenders
- Uttar Pradesh, Maharashtra, and Karnataka contributed most to sales
- Food, Clothing, and Electronics were top product categories
